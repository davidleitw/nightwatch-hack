# 獨立 Agent Usage view

## 目的與範圍

在 `http://127.0.0.1:4176/?source=live#topology` 右上角增加「Usage」入口，點擊切到同一應用的 `#usage` view，集中呈現 token、Prompt cache 命中率與用量趨勢區塊。提供「返回服務拓樸」連結。

**既有拓樸、調查側欄、事件、報告與歷史詳情面板的內容、樣式與行為維持原樣。** 新樣式限定在 `#usage-view` 與新的導覽入口。只在即時調查工作區啟用，不變動錄影／mock 畫面。

本次為呈現層調整，沿用現有 API；不修改後端、調查流程或模型。不新增套件、字型連線、圖表套件或建置設定。不新增自動化測試、不要求 reviewer；production build 與實際畫面確認後建立 MR，不自動合併。

## 資料與統計

- 進入 Usage view 時，使用既有 state 的進行中調查 ID；沒有進行中調查則使用最近一次結案 ID。沒有任何調查時顯示空狀態。
- 使用 `GET /api/investigations/{id}` 讀取該次 `usage`。標示調查 ID、進行中／最近一次調查，避免被誤認為帳號或跨調查總用量。
- 已於使用者指定的 `4176` 實測：前端代理到 `8006`；有完成調查回傳 `input_tokens: 108101`、`output_tokens: 3011`、`cache_read_tokens: 97300`、`cache_write_tokens: 9037`、`requests: 14`、`tool_calls: 13`。
- 總 token = `input_tokens + output_tokens`。
- 假設：`cache_read_tokens` 是包含於 `input_tokens` 的快取讀取量，因此命中率 = `cache_read_tokens / input_tokens × 100%`。延用舊資料相容性：只有未提供 `cache_read_tokens` 時才讀 `cached_tokens`，不混加兩者。
- 模型請求次數讀 `requests`，未提供時相容 `calls`；工具呼叫使用 `tool_calls`。快取寫入使用 `cache_write_tokens`。不修改既有 `readUsage` 或舊面板。
- 未回報數字顯示「—」；0 是有效數字。輸入 0 時命中率不適用。非數值、負數、不安全整數、快取讀取大於輸入等錯誤需可見，不以 0 代替。
- 本次不計算費用；回應中的 `cost` 未提供數值且沒有費率契約。

## 視覺結構

1. 頁首：Agent Usage、範圍說明、返回服務拓樸；沿用原有更新資料按鈕。
2. 調查摘要列：目前／最近一次調查、ID、狀態，提供查看報告連結。
3. 四張摘要卡：總 token、Prompt cache 命中率、模型請求、工具呼叫。主要數字突出，次要文案說明單位；命中率配比例條。
4. 趨勢區塊：總 token 與 cache rate 各一張圖表卡，清楚標示「尚無趨勢資料」。假設依「style 相關即可」，本次只有趨勢容器與無資料狀態；只有單一累計值，不能捏造折線、時間點、座標刻度或 0 值趨勢。
5. 明細區：輸入、輸出、快取讀取、快取寫入。補充統計公式與可展開原始值。
6. 白底卡片、綠色強調、細邊框、等寬數字及適當留白，沿用既有字型與配色。桌面 4 欄摘要／2 欄趨勢；窄螢幕依序縮成 2 欄與 1 欄，不影響原頁面。

## 更新與導覽

- 開啟 `#usage` 或按「更新資料」時取得該次詳情。重用原有事件更新取得的 detail，不新增輪詢或 API 端點。
- Usage view 隱藏拓樸與歷史 view，並隱藏原工作台的開始調查列；返回原路由恢復原面板。
- 支援直接開啟 `?source=live#usage`、瀏覽器前進／返回與右上角目前頁面標記。
- 詳情讀取失敗時顯示錯誤；不把其他調查或假資料當成此調查用量。

## 驗收

- 先確認原面板的前次修改已全部撤回，再實作獨立 view。
- `python3 console/build.py`、JavaScript 語法與 diff 空白檢查通過；無新依賴與 build 設定修改。
- 實際請求 `4176` 的 state/detail 與 production 靜態頁面，核對已有用量的呈現。
- 桌面、窄螢幕檢查新入口、Usage view、返回導覽；確認原面板未受新 CSS 影響。
- 不建立調查、不呼叫模型；關閉此次啟動的驗證程序。
- 無法操作的瀏覽器／趨勢序列驗證列在交付報告；MR 只包含本次 console 的 spec、view、樣式與報告。

## 待明訂契約

`contracts/` 尚未定義 usage；請確認快取讀取是否包含於輸入、不同後端欄位的統一名稱、未回報的表示，以及未來時間序列的資料來源。本次原樣讀取實際回應欄位，不新增或更名後端欄位。
